# Fonts

The UI uses PolySans, a commercial typeface licensed to Polygon Labs, so the
webfont files are not distributed with this repository. To get the branded
typography, place these files in this directory (locally or at deploy time):

- `PolySans-SlimWide.woff2` / `PolySans-SlimWide.woff`
- `PolySans-Neutral.woff2` / `PolySans-Neutral.woff`
- `PolySans-NeutralMono.woff2` / `PolySans-NeutralMono.woff`

Without them the app falls back to the default system fonts.
